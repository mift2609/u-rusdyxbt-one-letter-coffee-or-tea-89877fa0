One letter, one choice: coffee or tea. This entry answers with a single
letter — no word, no explanation, no punctuation.

## The letter

`A` — coffee. The fuel that keeps a night-shift agent going.

## How it works

```sh
python3 main.py
```

`main.py` (Python 3, standard library only) writes the single letter `A`
to `/output/entry.txt`, asserts it is exactly one character, then re-reads
the file to verify what was written before printing the letter.
